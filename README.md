# ⚡ VHDL Projects – FPGA Design and Implementation

This repository showcases my progression in **FPGA design** and **VHDL programming**, developed through a series of projects on the **Intel (Altera) Quartus Prime platform** and demonstrated on the **LogicalStep FPGA Development Board (MAX10)**.  

The work here reflects a broad foundation in **digital design**, from basic combinational logic to behavioral coding and finite state machines.  

---

## 📚 Concepts & Skills Learned

- **FPGA Project Setup**
  - Configuring Quartus projects and using TCL scripts for pin assignments  
  - Managing hierarchical VHDL designs with reusable components  

- **Combinational Logic Design**
  - Implementing gates, adders, multiplexers, and seven-segment decoders  
  - Building higher-level modules such as a simple ALU  

- **Behavioral VHDL**
  - Writing process constructs with `if-else` and `case` statements  
  - Developing on-chip testers and sequential control blocks  

- **Finite State Machines (FSMs)**
  - Designing Moore and Mealy state machines  
  - Applying FSMs to practical controllers such as traffic/crosswalk systems  

- **Synchronous Design Practices**
  - Understanding metastability and applying debouncing/filtering techniques  
  - Using clock enables and global clock networks to ensure reliable timing  

- **Simulation & Debugging**
  - Creating stimulus waveforms and analyzing outputs in ModelSim  
  - Debugging designs by comparing simulated results to truth tables  

- **Hardware Verification**
  - Downloading designs to FPGA hardware  
  - Testing with physical inputs and outputs (switches, buttons, LEDs, 7-segment displays)  

---

## 🛠️ Tools & Hardware

- **Quartus Prime (Intel/Altera)** – FPGA design and synthesis  
- **ModelSim-Altera** – functional simulation and waveform analysis  
- **VHDL** – Dataflow, Structural, and Behavioral coding styles  
- **LogicalStep FPGA Board (MAX10)** – with push buttons, switches, LEDs, and 7-segment displays
